Для работы с Deckhouse Stronghold необходимо получить у администратора параметры доступа. Вход в систему осуществляется через командную строку с утилитой `d8` или через веб-интерфейс, если он доступен в инсталляции.

Параметры доступа:

- адрес сервера Stronghold;
- способ и путь аутентификации;
- адрес веб-интерфейса, если вход выполняется через браузер;
- дополнительные параметры подключения, если они требуются в вашей инсталляции.

## Вход через CLI

Чтобы настроить доступ к своему проекту из командной строки, выполните следующие действия.

1. Установите [утилиту `d8`](/products/kubernetes-platform/documentation/v1/cli/d8).

1. Установите адрес сервера Stronghold в переменную окружения:

   ```shell
   export STRONGHOLD_ADDR=https://stronghold.domain.my
   ```

   Замените `https://stronghold.domain.my` на адрес, который вы получили от администратора.

1. Выполните вход через OIDC. Для этого авторизуйтесь в Stronghold с помощью команды:

   ```shell
   d8 stronghold login -path=oidc_deckhouse -method=oidc -no-print
   ```

   В примере используется [OIDC-аутентификация](../auth/oidc/overview/) по методу `oidc` и путь `oidc_deckhouse`. Если в вашей инсталляции используются другие параметры, укажите значения, предоставленные администратором.

   После запуска команды CLI открывает браузер для завершения входа через настроенного OIDC-провайдера. Если браузер не открылся автоматически, скопируйте URL из вывода команды и откройте его вручную.

1. Для проверки доступа используйте команду:

   ```shell
   d8 stronghold status
   ```

   Если команда выполняется успешно, адрес Stronghold указан корректно, аутентификация выполнена, и CLI-доступ работает.

Для работы с Deckhouse Stronghold используйте команды в формате:

```shell
d8 stronghold <command>
```

## Вход через веб-интерфейс

Если в вашей инсталляции доступен веб-интерфейс Stronghold, войдите через браузер:

1. Откройте адрес веб-интерфейса, предоставленный администратором.
1. Выберите способ входа, например OIDC.
1. При необходимости укажите имя роли или другие параметры, предоставленные администратором.
1. Авторизуйтесь.

После успешного входа Stronghold откроет пользовательский интерфейс с сответствующими правами доступа.

После входа рекомендуется создать первый секрет. Информация о том, как это сделать — в разделе [«Первый секрет»](../first-secret/).
