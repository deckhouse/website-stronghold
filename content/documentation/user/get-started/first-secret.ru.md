После успешного входа в Deckhouse Stronghold можно перейти к первой практической операции — записи и чтению секрета.

В этом примере используется механизм секретов `KV`.

{{< alert level="info" >}}
Механизм секретов `KV` может работать в двух режимах: `KV v1` — без версионирования и `KV v2` — с версионированием и дополнительными возможностями.В этом разделе используется базовый сценарий. Подробная информация о различиях между `KV v1` и `KV v2` приведена в профильных разделах документации [«Механизмы секретов KV»](../../secrets-engines/kv/overview/).
{{< /alert >}}

## Что нужно до начала

Перед выполнением примеров убедитесь, что:

- вход в Stronghold уже выполнен;
- у вас есть права на запись и чтение по выбранному пути;
- администратор предоставил доступ к `KV`-хранилищу.

Если вы ещё не входили в Stronghold, сначала выполните шаги из раздела [«Первый вход»](../first-login/).

1. Выберите путь для секрета

    Секреты в `KV`-хранилище записываются по пути.

    Для первого примера используйте тестовый путь:

    ```text
    secret/my-first-secret
    ```

    Если в вашей инсталляции используется другой путь монтирования, используйте значение, согласованное с администратором.

1. Запишите секрет

    Сохраните тестовый секрет следующей командой:

    ```bash
    d8 stronghold kv put secret/my-first-secret username=demo password=secret123
    ```

    Если операция завершилась успешно, Stronghold подтвердит запись секрета.

1. Прочитайте секрет

    Прочитайте сохранённый секрет:

    ```bash
    d8 stronghold kv get secret/my-first-secret
    ```

    В результате вы должны увидеть сохранённые значения.

    Пример вывода:

    ```text
    ====== Data ======
    Key         Value
    ---         -----
    password    secret123
    username    demo
    ```

1. Обновите секрет

    Если нужно изменить значение секрета, выполните повторную запись по тому же пути:

    ```bash
    d8 stronghold kv put secret/my-first-secret username=demo password=new-secret
    ```

    После этого снова прочитайте секрет:

    ```bash
    d8 stronghold kv get secret/my-first-secret
    ```

1. Удалите тестовый секрет

    После завершения проверки удалите тестовый секрет:

    ```bash
    d8 stronghold kv delete secret/my-first-secret
    ```

{{< alert level="info" >}}
Поведение удаления зависит от используемого режима: `KV v1` или `KV v2`. В `KV v2` удаление может быть мягким и использовать версионирование. Подробности приведены в профильных разделах по `KV`.
{{< /alert >}}

## Что происходит при работе с секретом

В базовом сценарии Stronghold позволяет:

- записывать значения по выбранному пути;
- читать сохранённые данные;
- обновлять значения;
- удалять секрет.

Именно так обычно начинается практическая работа с механизмом секретов `KV`.

## Если команда не работает

Если при записи или чтении секрета возникает ошибка, проверьте:

- успешно ли выполнен вход;
- действителен ли токен;
- есть ли у вас права на выбранный путь;
- правильно ли указан путь монтирования;
- включён ли соответствующий механизм секретов.

Если проблема сохраняется, обратитесь к администратору Stronghold.
