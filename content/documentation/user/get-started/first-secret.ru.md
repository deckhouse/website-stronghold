После успешного входа в Deckhouse Stronghold можно создать первый тестовый секрет, проверить его содержимое и при необходимости изменить значение.

В этом примере используется механизм секретов `KV`. Перед выполнением команд убедитесь, что у вас есть права на запись и чтение по выбранному пути, а администратор предоставил доступ к `KV`-хранилищу.
Если вы ещё не входили в Stronghold, сначала выполните шаги из раздела [«Настройка доступа»](../access/).

{{< alert level="warning" >}}
Используйте в примере только тестовые значения. Не сохраняйте реальные пароли, токены и ключи в тестовых секретах.
{{< /alert >}}

## Создание секрета

В примерах ниже используется тестовый путь `secret/my-first-secret` и тестовые ключи `username` и `password`. Если в вашей инсталляции используется другой путь монтирования, замените `secret` на путь, который сообщил администратор.

1. Выберите путь для секрета

    Секреты в `KV`-хранилище записываются по пути.

    Для первого примера используйте тестовый путь:

    ```text
    secret/my-first-secret
    ```

    По этому пути Stronghold сохранит набор ключей и значений.

1. Создайте секрет

    Запишите тестовые значения по выбранному пути:

    ```bash
    d8 stronghold kv put secret/my-first-secret username=demo password=secret123
    ```

    Если операция завершилась успешно, Stronghold подтвердит запись секрета.

1. Проверьте секрет

    Прочитайте сохранённые значения:

    ```bash
    d8 stronghold kv get secret/my-first-secret
    ```

    В результате вы должны увидеть сохранённые значения.

    Пример вывода:

    ```text
    ====== Data ======
    Key         Value
    ---         -----
    password    secret123
    username    demo
    ```

1. Обновите секрет

    Чтобы изменить значение, запишите секрет по тому же пути ещё раз:

    ```bash
    d8 stronghold kv put secret/my-first-secret username=demo password=new-secret
    ```

    Затем снова прочитайте секрет и убедитесь, что значение изменилось:

    ```bash
    d8 stronghold kv get secret/my-first-secret
    ```

{{< alert level="info" >}}
После проверки замените тестовый путь и значения на параметры, которые используются в вашем проекте. Дополнительные возможности механизма `KV`, включая особенности версионирования, описаны в разделе [«Механизмы секретов KV»](../../secrets-engines/kv/overview/).

Если команда возвращает ошибку доступа или пути, проверьте путь монтирования и права на чтение и запись. Ошибки входа устраните по инструкции [«Настройка доступа»](../access/).
{{< /alert >}}
