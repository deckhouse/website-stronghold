В этом разделе собраны инструкции по настройке OIDC-аутентификации для разных провайдеров в Deckhouse Stronghold.

Сначала ознакомьтесь с [общим обзором OIDC](../overview). На этой странице описаны назначение OIDC-аутентификации, её место в Deckhouse Stronghold и общие принципы настройки.

После этого перейдите к инструкции для нужного провайдера.

## Доступные провайдеры

В документации доступны следующие инструкции:

- [GitLab](./gitLab) — используйте, если GitLab выступает источником идентификации.
- [Keycloak](./keycloak) — используйте, если аутентификация построена на Keycloak.
- [Kubernetes](./kubernetes) — используйте, если нужен сценарий аутентификации, связанный с OIDC-возможностями Kubernetes.
