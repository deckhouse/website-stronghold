Механизм секретов `kv` — это общее хранилище типа «ключ–значение» для произвольных секретов в настроенном физическом хранилище Stronghold.

Он может работать в двух режимах:
- `kv` версии 1 — для хранения одного актуального значения по ключу;
- `kv` версии 2 — с версионностью и возможностью хранить настраиваемое количество версий для каждого ключа.

## KV версия 1

В режиме `kv` версии 1 без поддержки версионности для ключа сохраняется только последнее обновлённое значение.

Основное преимущество этого режима — меньшее потребление места в хранилище для каждого ключа, так как не сохраняются дополнительные метаданные и история изменений.

Кроме того, запросы к такому механизму секретов обычно выполняются быстрее, так как для каждого запроса требуется меньше обращений к хранилищу данных и не возникает блокировка при изменении значения ключа.

## KV версия 2

В `kv` версии 2 для каждого ключа можно хранить настраиваемое количество версий. По умолчанию сохраняется 10 версий.

Из каждой сохранённой версии можно извлечь как данные, так и метаданные. Для защиты от случайной перезаписи данных можно использовать операции Check-and-Set.

При удалении версии базовые данные не удаляются сразу, а помечаются как удалённые. Такое удаление можно отменить.

Чтобы удалить данные версии окончательно, используйте команду `destroy` или отправьте запрос в соответствующий эндпоинт API.

Чтобы удалить все версии и метаданные ключа, используйте команду `delete` для метаданных или соответствующий эндпоинт API.

Для этих операций можно настроить разные ACL, чтобы отдельно управлять правами на мягкое удаление, восстановление и окончательное удаление данных.

## Использование

Для работы с механизмом секретов `kv` используйте команду `d8 stronghold kv <подкоманда> [options] [args]`.

Доступные подкоманды перечислены в таблице ниже:

| Подкоманда | `kv` v1 | `kv` v2 | Описание |
| --- | --- | --- | --- |
| `delete` | x | x | Удаляет версии секретов из `kv` |
| `destroy` | — | x | Окончательно удаляет одну или несколько версий секрета |
| `enable-versioning` | — | x | Включает версионность для существующего хранилища `kv` v1 |
| `get` | x | x | Получает данные |
| `list` | x | x | Перечисляет данные или секреты |
| `metadata` | — | x | Выполняет операции с метаданными хранилища `kv` |
| `patch` | — | x | Обновляет секреты без перезаписи существующих значений |
| `put` | x | x | Создаёт или обновляет секреты с заменой существующих значений |
| `rollback` | — | x | Откатывает секрет к предыдущей версии |
| `undelete` | — | x | Восстанавливает удалённую версию секрета |
