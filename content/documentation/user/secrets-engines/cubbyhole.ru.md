---
title: "Механизм секретов Cubbyhole"
weight: 30
---

Механизм секретов `cubbyhole` используется для хранения произвольных секретов в хранилище, привязанном к токену.
Пути в `cubbyhole` распределяются по токенам.
Ни один токен не может получить доступ к `cubbyhole` другого токена.
Когда срок действия токена истекает, его `cubbyhole` уничтожается.

В отличие от механизма секретов `kv`, время жизни `cubbyhole` связано со временем жизни токена аутентификации.
Поэтому для значений, хранящихся в `cubbyhole`, не используются TTL или интервал обновления.

Запись по ключу в механизме секретов `cubbyhole` полностью заменяет предыдущее значение.

## Настройка

Большинство механизмов секретов необходимо предварительно настроить, прежде чем они смогут выполнять свои функции.
Обычно эти действия выполняет оператор или инструмент управления конфигурацией.

Механизм секретов `cubbyhole` включён по умолчанию.
Его нельзя отключить, переместить или включить несколько раз.

## Использование

После настройки механизма секретов и получения токена с соответствующими правами можно записывать ключи с произвольными значениями.

Выполните следующие действия:

1. Запишите произвольные данные.

   ```console
   $ d8 stronghold write cubbyhole/my-secret my-value=s3cr3t

   Success! Data written to: cubbyhole/my-secret
   ```

1. Прочитайте произвольные данные.

   ```console
   $ d8 stronghold read cubbyhole/my-secret

   Key         Value
   ---         -----
   my-value    s3cr3t
   ```
