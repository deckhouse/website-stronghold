## identity

### POST /identity/alias

**ID операции:** `alias-create`

Создать новый псевдоним.

#### Параметры тела запроса

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `canonical_id` | string | нет | Идентификатор сущности, которой принадлежит этот псевдоним |
| `entity_id` | string | нет | Идентификатор сущности, которой принадлежит этот псевдоним. Это поле устарело в пользу 'canonical_id'. |
| `id` | string | нет | Идентификатор псевдонима |
| `mount_accessor` | string | нет | Аксессор точки монтирования, к которой относится этот псевдоним |
| `name` | string | нет | Имя псевдонима |

#### Ответы

**200**: OK

### POST /identity/entity/merge

**ID операции:** `entity-merge`

Объединить две или более сущностей

#### Параметры тела запроса

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `conflicting_alias_ids_to_keep` | array | нет | Идентификаторы псевдонимов, которые следует сохранить при конфликте псевдонимов. Игнорируется, если конфликтов нет |
| `force` | boolean | нет | Если задан, при слиянии секретов MFA применяется стратегия 'mine': если секреты одного типа есть и в объединяемых сущностях, и в целевой сущности, секреты целевой сущности не изменяются. Если не задан, API возвращает ошибку со списком всех конфликтов. |
| `from_entity_ids` | array | нет | Идентификаторы объединяемых сущностей |
| `to_entity_id` | string | нет | Идентификатор сущности, в которую объединяются все остальные сущности |

#### Ответы

**200**: OK
