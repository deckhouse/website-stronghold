## auth

### GET /auth/token/accessors

**ID операции:** `token-list-accessors`

Возвращает список аксессоров токенов, с помощью которых затем можно перебрать токены, получить их свойства или отозвать их. Поскольку это может привести к отказу в обслуживании, для этой конечной точки помимо права 'list' требуется право 'sudo'.

**Требует sudo:** да

#### Параметры

| Параметр | Тип | Расположение | Обязательный | Описание |
|----------|-----|--------------|--------------|----------|
| `list` | string (true) | query | да | Должно быть установлено значение `true`. |

#### Ответы

**200**: OK

### POST /auth/token/roles/{role_name}

**ID операции:** `token-write-role`

**Поддерживается создание:** да

#### Параметры

| Параметр | Тип | Расположение | Обязательный | Описание |
|----------|-----|--------------|--------------|----------|
| `role_name` | string | path | да | Имя роли |

#### Параметры тела запроса

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `allowed_entity_aliases` | array | нет | Строка или JSON-список разрешенных псевдонимов сущностей. Если задан, определяет псевдонимы сущностей, которые разрешено использовать при генерации токенов. Поддерживает glob-шаблоны. |
| `allowed_policies` | array | нет | Если задан, токены можно создавать с любым подмножеством политик из этого списка, а не только с подмножеством политик вызывающего токена, как обычно. Значение — строка имен политик через запятую. |
| `allowed_policies_glob` | array | нет | Если задан, токены можно создавать с любым подмножеством политик, соответствующих glob-шаблонам из этого списка, а не только с подмножеством политик вызывающего токена, как обычно. Значение — строка glob-шаблонов имен политик через запятую. |
| `bound_cidrs` | array | нет | ⚠️ Устарело. Используйте вместо этого 'token_bound_cidrs'. |
| `disallowed_policies` | array | нет | Если задан, токен через эту роль будет создан, только если не запрошена ни одна политика из этого списка. Значение — строка имен политик через запятую. |
| `disallowed_policies_glob` | array | нет | Если задан, токен через эту роль будет создан, только если ни одна из запрошенных политик не соответствует glob-шаблонам из этого списка. Значение — строка glob-шаблонов имен политик через запятую. |
| `explicit_max_ttl` | integer | нет | ⚠️ Устарело. Используйте вместо этого 'token_explicit_max_ttl'. |
| `orphan` | boolean | нет | Если true, токены, созданные через эту роль, будут токенами-сиротами (без родителя). |
| `path_suffix` | string | нет | Если задан, токены, созданные через эту роль, будут содержать указанный суффикс в своем пути. Это упрощает последующее использование конечной точки 'revoke-prefix'. Суффикс должен соответствовать регулярному выражению \w[\w-.]+\w |
| `period` | integer | нет | ⚠️ Устарело. Используйте вместо этого 'token_period'. |
| `renewable` | boolean (default: True) | нет | Определяет, можно ли продлевать токены, созданные через эту роль. По умолчанию "true". |
| `token_bound_cidrs` | array | нет | Строка значений через запятую или JSON-список CIDR-блоков. Если задан, определяет диапазоны IP-адресов, которым разрешено использовать сгенерированный токен. |
| `token_explicit_max_ttl` | integer | нет | Если задан, токены, созданные через эту роль, получают явный максимальный TTL. При продлении текущие значения максимального TTL роли и точки монтирования не проверяются, и их изменение не влияет на продлеваемый токен. |
| `token_no_default_policy` | boolean | нет | Если true, политика 'default' не будет автоматически добавляться к сгенерированным токенам |
| `token_num_uses` | integer | нет | Максимальное количество использований токена; 0 означает без ограничений |
| `token_period` | integer | нет | Если задан, токены, созданные через эту роль, не будут иметь максимального срока жизни; вместо этого их период продления фиксируется на этом значении. Принимает целое число секунд или строку длительности (например, "24h"). |
| `token_type` | string (default: default-service) | нет | Тип генерируемого токена: service или batch |

#### Ответы

**200**: OK
